# 对抗环境：

## 坐标系构建

整个环境由两个坐标系构成，分为惯性坐标系和随动坐标系，惯性坐标系用于衡量实体在环境中的绝对信息，随动坐标系用于衡量实体间的相对信息，惯性坐标系修改成以北方向为x轴，以东方向为z轴，以垂直向上为y轴，单机随动坐标系修改成x轴指向实体运动方向，y轴指向运动方向垂直向上，z轴与x，y轴构成右手坐标系

## 环境初始化设置

对抗环境为24红方v4-6蓝方，以惯性坐标系原点作为蓝方集群生成中心点，在中心点附近20km范围内随机生成不同数量的蓝方飞机，高度8-12km，速度三四百m/s左右（初始化配置接口暴露），红方集群生成在以蓝方飞机中心点为圆心、半径140-160km左右的60°区域，初始化典型发射速度0.6-0.9Ma，高度8-10km，初始化配置接口暴露，速度方向大致指向蓝方初始化中心点方向（增加15°以内的偏置）

# 蓝方集群

蓝方探测范围半径为60km，当前使用规则机策略根据环境态势生成动作库索引选择动作进入环境进行迭代，每0.1s输出索引，环境每0.005s进行迭代

# 红方集群

初始化后应该进行7s左右的加速助推爬升到达最大速度6马赫，然后进行导引阶段，环境能够根据比例导引系数3.5和强化学习输出的过载偏置合成一个总过载在环境里进行步进，步进的时候考虑气动参考面积、随环境变化的阻力系数、诱导阻力因子、最大过载35g、最大制导时间180s、捕获视场角35°、跟踪视场角60°、视场脱锁保持时间0.75s、过最近点增长距离600m、过最近点远离速度40m/s、杀伤半径5m，以上参数需要暴露接口可配置

红方策略网络分为高层目标分配网络与低层策略网络。高层输出满足单目标最大分配数量约束的联合目标分配，并保持目标分配稳定；默认每5.0s重新决策，目标毁伤或导弹失效时允许立即重决策。目标短时失锁时不触发高层重分配，由低层使用环境维护的锁定保持或惯性预测状态继续制导。低层输出叠加在比例导引指令上（比例导引系数为3.5）的二维有界偏置量，偏置模长默认不超过5g，仅用于辅助比例导引进行制导，最终合成过载仍受35g限制

## 红方高层网络

### actor网络

输入包括自身状态（绝对坐标系下的位置、速度；马赫数、可用过载、存活标志、剩余制导时间、导引头状态）、友方状态（所有友方在自身随动坐标系下的位置、速度；可用过载、存活标志、剩余制导时间）、自身探测到的蓝方目标状态（所有探测到的目标在自身随动坐标系下的位置、速度、存活标志、轨迹置信度）、弹目关系状态（距离、闭合速度、预计拦截时间、视线角速率、ZEM、可达概率、是否为当前目标、当前分配数与剩余容量）、当前目标分配关系以及环境上下文信息（全局剩余时间、双方存活数量、每个目标允许分配的最大导弹数、未分配导弹数）。当前目标通过导弹—目标关系表示，不把目标编号作为连续数值特征。以上输入经 MLP 编码 → 导弹集群与目标集群自注意力 → 弹目关系编码 → 以当前导弹特征为 Query、目标特征为 Key/Value 做交叉注意力 → 融合全局上下文 → GRU → 自回归目标概率输出头，逐弹更新当前部分分配数与剩余容量，最终输出满足容量约束的联合目标分配及联合动作概率

### critic网络

输入包括全局红方集群集合（所有红方在惯性坐标系下的位置、速度；可用过载、存活标志、剩余制导时间、导引头状态、当前偏置）、全局蓝方集群集合（所有蓝方在惯性坐标系下的位置、速度、存活标志）、全局弹目关系、当前目标分配矩阵以及环境上下文信息（全局剩余时间、双方存活数量、已毁伤比例、累计无效损失比例、未分配导弹比例），经独立编码、集合自注意力、红蓝交叉注意力和全局池化后输入价值头，输出5维潜在团队价值分量并求和得到用于训练的团队标量价值；当前不对各价值分量施加独立语义监督

最终各actor网络的条件输出合并为一个整体目标分配矩阵，每个目标最多分配配置允许数量的存活导弹；训练时保存自回归采样顺序并计算联合log-prob，推理与可视化使用同一分配矩阵

## 红方低层网络

### actor网络

输入包括自身状态（惯性坐标系下的位置、速度；马赫数、可用过载、存活标志、剩余制导时间、导引头模式、目标估计龄期、当前PN指令、前一偏置、过载饱和余量）、友方状态（与自身攻击相同目标的所有友方在自身随动坐标系下的位置、速度；可用过载、存活标志、剩余制导时间、预计拦截时间、ZEM、前一偏置）、上层指定目标状态（该目标在自身随动坐标系下的相对位置、相对速度、LOS、LOS角速率、闭合速度、预计拦截时间、ZEM、轨迹置信度、存活标志）以及环境上下文信息（全局剩余时间、同目标友弹数量、目标总分配数量、高层动作龄期），经 MLP 分别编码 → 对同目标友方导弹集合进行自注意力和池化 → 以自身导弹特征为 Query、目标特征为 Key/Value 做交叉注意力 → 融合全局上下文 → GRU → 连续动作输出头，最终输出附加在比例导引指令上的二维有界偏置量。目标短时失锁时使用环境维护的锁定保持或惯性预测状态并保留GRU记忆；导弹失效、目标失效或目标槽位变化时重置对应目标记忆

### critic网络

输入包括全局红方集群集合、全局蓝方集群集合、全局弹目关系、完整目标分配矩阵、全部导弹前一偏置以及环境上下文信息，经红方集合编码、蓝方集合编码、偏置量编码 → 集合自注意力与红蓝交叉注意力 → 保留每枚红方导弹对应的特征 → 融合环境上下文 → 逐弹价值头，最终为每枚红方导弹输出5维潜在价值分量并求和得到用于训练的逐弹标量价值；当前不对各价值分量施加独立语义监督，也不把逐弹奖励或优势预先求团队平均

各actor网络的输出合并为整体导引偏置矩阵，矩阵每一行对应一枚红方导弹，每一列对应一个偏置分量；该矩阵输入底层制导控制模块，与比例导引指令叠加形成最终过载指令，并用于后续可视化各导弹的底层机动控制效果。
